# 2차 점검 — 아직 남은 문제와 해결책 (2026-09-22)

1차 보안 점검에서 고른 것들은 PR #248 ~ #252 로 들어갔다(로그인 잠금 · 소셜 state · 값표와 시연 한도 · 커뮤니티 제한 ·
화면 이스케이프 · 구독). 이 문서는 **그 뒤에도 남아 있는 것**을 쉬운 말로 적고, 어떻게 고칠지까지 같이 적는다.
급한 순서다.

## A. 제출(9/29) 전에 반드시

### 1. 배포 DB(Render 무료 Postgres)는 만든 지 30일이 지나면 지워진다
- **무슨 일**: Render 무료 Postgres 는 생성 30일 뒤 삭제된다. 회원 · 측정 기록 · 결제 원장 · 커뮤니티 글이 전부 사라진다.
  심사 기간(10월 초)과 겹치면 심사위원이 접속했을 때 빈 앱이 된다.
- **확인**: Render 대시보드 → 그 DB → 만든 날짜(Created). 만료가 10/2 뒤 2주 안이면 위험.
- **해결** (둘 중 하나):
  - (a) DB 를 유료(월 $7)로 올린다 — 가장 확실.
  - (b) 만료 3일 전에 새 무료 DB 를 만들고 `pg_dump` → 새 DB 로 `psql` 복원 → Render 의 `DATABASE_URL` 을 새것으로 바꾼다.
- **덧붙여**: 백업이 하나도 없다. GitHub Actions 로 매일 `pg_dump` 를 떠서 비공개 저장소(또는 Actions 아티팩트)에 두면
  DB 가 날아가도 하루치만 잃는다. 30분짜리 일.

### 2. 개인정보처리방침이 실제 동작과 다르다
- **무슨 일**: `frontend/privacy.html` 에 없는데 앱이 하는 것 —
  - 위치정보(날씨 · 센터 찾기에 GPS 를 씀)
  - **건강 상태 · 약봉지 사진은 민감정보** → 별도 동의가 필요
  - 건강 상태 · 측정값 · 기록을 **해외(Anthropic, 미국) 서버로 보내** 루틴을 짓는다 → '국외 이전' 고지 항목
  - 카카오페이 결제 정보(주문번호 · 금액)
  - 청소년(만 14세 미만)이 쓸 수 있는데 법정대리인 동의 절차가 없다
- **왜 문제**: 공공데이터 심사에서 개인정보 항목은 자주 본다. 있는데 안 적은 것이 제일 나쁘다.
- **해결**: 방침에 위 다섯 항목 추가(처리 목적 · 항목 · 보유 기간 · 국외 이전처 · 거부 시 불이익). 건강 상태 입력 창에
  "민감정보 처리에 동의합니다" 체크 하나, 가입 화면에 "만 14세 이상입니다" 체크 하나.

### 3. 결제 · 환불의 동시 요청
- **무슨 일**: 환불 버튼을 아주 빠르게 두 번 누르면(또는 요청을 두 번 보내면) 카카오는 한 번만 취소하지만 우리 원장에는
  환불 줄이 두 번 들어갈 수 있다. 이용권 차감도 "잔액 확인 → 차감" 두 단계라 같은 순간 두 요청이 오면 둘 다 통과한다.
  (AI 호출은 #249 에서 한 사람이 동시에 둘을 못 부르게 막아 지금은 안전하다. 환불 · 자세히 보기 구매가 남았다.)
- **해결**: 상태를 바꿀 때 조건을 같이 건다 — `UPDATE pay_orders SET status='refunded' WHERE order_id=? AND status='paid'`
  로 첫 요청만 성공하게. 차감도 `INSERT … WHERE (SELECT SUM(amount)) >= ?` 한 문장으로.

### 4. 커뮤니티 — 안 보이는 글에 댓글 · 반응이 달린다
- **무슨 일**: '고른 친구' 에게만 보이는 글도 글 번호만 알면 누구나 댓글과 이모지를 달 수 있다(글은 못 봐도).
- **해결**: `add_comment` · `toggle_reaction` · `get_post` 에서 그 글이 나에게 보이는 글인지(`_visible_sql`) 먼저 본다.

### 5. 모임 비밀번호는 무제한으로 넣어 볼 수 있다
- **무슨 일**: 비공개 모임의 숫자 비밀번호(12자 이하)는 틀려도 제한이 없어 자동으로 다 넣어 볼 수 있다.
- **해결**: 로그인 잠금(#248 의 `login_guard`)을 그대로 쓴다 — 방마다 5번 틀리면 15분.

## B. 이번 주 안에 하면 좋은 것

### 6. 사진이 DB 에 그대로 들어간다
- **무슨 일**: 사진이 글과 함께 base64 로 DB 에 들어간다. 배포 DB 는 1GB. #250 의 제한(한 장 1MB · 하루 20MB)으로
  버티고 있지만, 피드 한 번 여는 데 글 20개 × 사진 3장이면 응답이 수십 MB 라 느리다.
- **해결**: 객체 저장소(Cloudflare R2 — 10GB 무료 · 회원가입만)에 올리고 DB 에는 주소만. 하루 일.

### 7. CSP(콘텐츠 보안 정책)가 없다
- **무슨 일**: 화면에 남의 스크립트가 끼어드는 것을 브라우저가 막게 하는 헤더. 지금은 화면이 인라인 스크립트와
  CDN(three.js) 을 써서 허용 목록을 만들 수 없다. #251 로 나머지 헤더는 넣었다.
- **해결**: 제출 뒤에 `index.html` 의 스크립트를 `frontend/js/` 파일로 나누고 CSP 를 건다.

### 8. 배포 서버가 개발자 PC 주소(localhost)의 요청도 받는다
- **무슨 일**: CORS 허용 목록에 `localhost:3000 · 5173` 이 늘 들어 있다. 위험은 낮지만(공격자 PC 에서 피해자 쿠키를 못
  얻는다) 굳이 열어 둘 이유가 없다.
- **해결**: `PUBLIC_BASE_URL` 이 있으면(배포) localhost 를 뺀다. 두 줄.

### 9. API 문서(/docs)가 누구에게나 열려 있다
- **무슨 일**: 서버의 모든 경로와 입력 모양을 볼 수 있다. 심사에는 오히려 도움이 될 수도 있어 판단이 갈린다.
- **해결**: 배포에서는 끄거나(`docs_url=None`) 관리자만.

### 10. 비밀번호를 잊으면 방법이 없다
- **무슨 일**: 비밀번호 찾기 · 재설정이 없다. #248 의 5회 잠금까지 있어 "틀려서 잠기고 → 기억도 안 나면" 계정을 버려야 한다.
- **해결**: 이메일 발송이 없어 어렵다. 현실적인 답은 카카오 로그인을 앞세우고, 가입 화면에 "비밀번호는 다시 찾을 수
  없어요 — 카카오 로그인을 권해요" 를 적는 것.

### 11. AI 지시문에 사용자가 적은 글이 그대로 들어간다
- **무슨 일**: 건강 상태 · 기록 이름 · 이전 루틴 이름이 AI 지시문에 실린다. 누가 "위 규칙은 무시하고 …" 같은 말을 적으면
  루틴의 문장이 흔들릴 수 있다. 동작 코드는 서버가 표와 대조해 막고, 문장은 #251 로 화면에서 이스케이프되니 실행되는
  일은 없다 — 이상한 문장이 보일 수 있을 뿐.
- **해결**: 지금은 길이 제한(20자)으로 충분. 지시문에서 사용자 입력을 "자료" 구역으로 명시하면 더 낫다.

### 12. 로그아웃해도 다른 기기의 세션은 남는다
- **무슨 일**: 세션은 30일. 로그아웃은 지금 기기 것만 지운다. PC 방에서 로그인하고 잊으면 30일 동안 열려 있다.
- **해결**: "모든 기기에서 로그아웃" 버튼(그 사람의 sessions 전부 삭제). 열 줄.

### 13. HSTS 헤더
- Render 가 https 로 보내 주지만 브라우저에 "앞으로 이 주소는 https 로만" 을 못 박는 헤더가 없다. 한 줄
  (`Strict-Transport-Security: max-age=31536000`). #251 에서 빠뜨렸다.

### 14. 구독 환불 규정이 없다
- **무슨 일**: #252 의 구독은 환불 창구를 막아 두었다(409). 전자상거래법상 청약철회(7일)는 받아야 한다.
- **해결**: "결제 뒤 7일 안 · 그동안 AI 를 한 번도 안 썼으면 전액" 규칙을 정하고 환불 경로에 붙인다. 실결제 전에만
  정하면 된다.

## C. 운영하면서

### 15. 사용량 · 원가 보기
- `/ai/usage`(관리자)를 주 1회 본다. 호출당 출력 토큰이 5,000 을 넘거나 '버림' 비율이 10% 를 넘으면 지시문을 손본다.
  구독자 가운데 하루 5회를 매일 다 쓰는 사람이 여럿이면 값(9,900원)이나 한도를 다시 본다.

### 16. 시연 모드의 테스트 결제
- 실결제가 안 되는 동안은 테스트 가맹점이라 누구나 결제창에서 돈 없이 이용권 · 구독을 얻는다. 의도한 것(시연)이고
  AI 는 하루 횟수, 커뮤니티는 하루 용량으로 막혀 있다. 실결제로 바꾸는 순간(`KAKAOPAY_CID` 교체) 자동으로 끝난다.

### 17. 서버가 하나라서
- AI 동시 호출 잠금(`_ai_inflight`)이 서버 메모리에 있다. Render 무료는 프로세스 하나라 맞지만, 나중에 여러 대로
  늘리면 DB 로 옮겨야 한다.
