# 250 고정 루틴 데이터 스키마

`data/sample/routines_250.json` (정식 데이터는 `data/processed/routines_250.json` — 있으면 우선).

원본: 상위 폴더 `루틴250_연령대5x목적5.md`. 이 JSON은 그 표를 **그대로 옮긴 것**이고,
`backend/routines.py` 가 읽어 `/program/routine` 으로 내보낸다. 코드는 루틴을 새로 만들지 않는다.

```
연령대 5 (유아기·유소년·청소년·성인·어르신)
  × 목적 5 (다이어트·기초 체력 증진·재활 및 기능 회복·수험생 체력 증진·유연성 강화)
  = 25 조합, 조합마다 루틴 10개
루틴 1개 = 준비운동 1 + 본운동 3 + 정리운동 1 (코드 5개)
```

## 최상위 구조

```jsonc
{
  "_meta":   { "샘플여부": true, "조합수": 25, "루틴수": 250, ... },
  "config":  { ... },          // 순환·강도·재프레이밍·안전문구
  "pools":   { "<연령대>": { "준비운동": {...}, "본운동": {...}, "정리운동": {...} } },
  "routines":{ "<연령대>": { "<목적>": [ <루틴> x10 ] } }
}
```

## `pools[연령대][단계][코드]` — 동작 하나

| 필드 | 예 | 뜻 |
|---|---|---|
| `동작` | `"스쿼트 (무릎 불편 시 의자 스쿼트)"` | 화면에 뜨는 이름 |
| `체력요인` | `["근력·근지구력(하체)"]` | 대체 동작을 고를 때 매칭 기준 |
| `도구` | `"맨몸"` \| `"의자"` \| `"페트병"` \| `"페트병+의자"` | 페트병은 KSPO 조회 시 `맨몸` |
| `유형` | `"횟수"` \| `"시간"` | 시간형이면 강도가 `초`로 나감 |
| `부담부위` | `["무릎"]` \| `[]` | **무릎/허리/어깨** 중. 제외 부위와 겹치면 교체 |
| `kspo` | `{"대상":"성인","체력항목":"근력·근지구력","도구":"맨몸","부위":"하체"}` | 서비스키 확보 후 영상 조회 필터 (8절) |

코드 접두어: 유아기 `FW/FA/FC`, 유소년 `YW/YA/YC`, 청소년 `TW/TA/TC`, 성인 `W/A/C`, 어르신 `EW/E/EC`.

## `routines[연령대][목적]` — 루틴 10개 (배열)

```jsonc
{ "no": 1, "name": "서킷 1",
  "prep": ["W2"], "main": ["A1","A9","A7"], "cool": ["C1"],
  "steps": ["W2","A1","A9","A7","C1"] }        // prep+main+cool, 편의용
```

`no` 는 1..10 연속. `day` (0-based 경과일)에 대해 `no = (day % 10) + 1`.

## `config`

| 키 | 뜻 |
|---|---|
| `counts` | `{"준비운동":1,"본운동":3,"정리운동":1}` |
| `cycle_days` | `10` — 순환 주기 |
| `age_minutes` | `{"유아기":[5,8], "청소년":[10,15], ...}` — 연령대별 루틴 시간 |
| `reframe` | `{"어르신":{"재활 및 기능 회복":"낙상 예방 중심", ...}}` — 화면 표시명 |
| `purpose_factors` | 목적 → 우선 체력요인 |
| `intensity.weeks` | `"1-4"/"5-8"/"9-12"` 구간별 `{연령대:{reps,sets}}` + `시간형:{sec,sets}` |
| `intensity.heavy_day` | `{"main_count":2,"sets":1,"time_ratio":0.5}` |
| `safety_note` | 모든 루틴 하단 고정 문구 |

## 규칙 (backend/routines.py 가 지킨다)

- **순환**: 조합의 루틴 10개를 `1→2→…→10→1` 로 매일 하나씩. 3개월 ≈ 9바퀴.
- **제외 부위**: 본운동의 `부담부위` 가 제외 부위와 겹치면 **같은 `체력요인` 의 다른 본운동 코드**로 교체.
  후보가 없으면 요인 조건을 먼저 완화, 그래도 없으면 그 동작을 건너뛴다. **제외·안전 조건은 절대 완화하지 않는다.**
- **몸 무거운 날**: 본운동 3 → 앞 2개, 세트 1세트, 시간형 시간 절반.
- **시작 강도**: 추정 체력나이가 실제 나이보다 +7세↑ (또는 집중개선영역 2개↑) → 한 구간 낮게 시작(`offset -1`).
  −7세↓ → 한 구간 높게. 체력이 낮은 사람에게 더 센 운동을 주지 않는다.

## 정식 데이터로 교체할 때

같은 구조의 `routines_250.json` 을 `data/processed/` 에 두면 자동으로 그쪽을 쓴다.
`backend/routines.py` 는 필드명을 그대로 참조하므로 스키마만 맞추면 코드 수정이 필요 없다.
