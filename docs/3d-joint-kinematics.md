# 사람 관절은 어떻게 꺾이나 — 3D 동작을 만들고 검사하는 기준

3D 동작(`frontend/js/move-3d.js` 의 PROC·TWEAKS, Mixamo 모션캡처)을 볼 때 "관절이 이상하게 꺾여 있다"는 것을
감으로 고치지 않고, **사람 관절의 움직이는 방향과 정상 범위**를 기준으로 고치고 검사하기 위해 정리한 문서다.
검사 스크립트(`docs/3d/qa_sample.js` → `docs/3d/qa_check.py`)의 한계값은 여기서 나온다.
동작마다의 바른 자세 설명은 [`3d-exercise-form-notes.md`](./3d-exercise-form-notes.md) 에 있고, 이 문서는 그 자세를 **관절 각도**로 옮긴 것이다.

> 범위 값은 성인 평균이고 사람마다 ±10° 쯤 다르다 (출처는 맨 아래). 우리 캐릭터는 "보통 사람"이므로 평균 안에서만 움직이게 한다.
> 각도는 해부학적 자세(똑바로 서서 팔을 내리고 손바닥이 앞을 보는 자세)를 0° 로 잰다.

## 1. 관절별 움직임과 정상 범위

| 관절 | 종류 | 움직임 | 정상 범위 | 우리 3D 에서 지키는 것 |
|---|---|---|---|---|
| **무릎** | 경첩 | 굽힘(flexion) | 능동 135°, 수동 150° (종아리가 허벅지에 닿을 때) | 정강이는 **허벅지 뒤쪽으로만** 굽는다. 옆(내반·외반)·앞(과신전)으로 꺾이면 안 된다 |
| | | 폄(extension) | 0° (과신전 0~5°까지 정상) | 굽힘 8° 이상이 뒤쪽 아닌 방향이면 잘못 |
| | | 회전 | 굽힌 상태에서만 안쪽 10°, 바깥쪽 30~40° | 무릎을 편 채로 정강이를 비틀지 않는다 |
| **고관절** | 절구 | 굽힘 | 무릎 굽힌 채 120°, 무릎 편 채 80~90° (햄스트링이 막는다) | 140° 넘으면 잘못 (골반이 같이 기울면 더 가 보인다) |
| | | 폄 | 능동 10~20°, 수동 30° | 다리를 뒤로 35° 넘게 보내지 않는다 (런지 뒷다리·브리지가 흔한 실수) |
| | | 벌림/모음 | 벌림 40~45°, 모음 20~30° (다리를 몸 가운데 너머로) | 벌림 55°, 모음 40° 넘으면 잘못 |
| | | 회전 | 안쪽 35~45°, 바깥쪽 45° | 무릎 방향은 발끝 방향 |
| **발목** | 경첩 | 발등 굽힘(dorsiflexion) | 15~20° (무릎 편 채), 20~30° (무릎 굽힌 채) | 40° 넘으면 잘못 |
| | | 발바닥 굽힘(plantarflexion) | 40~50° | 55° 넘으면 잘못 |
| | 거골하 | 안쪽/바깥쪽 뒤집기(inversion/eversion) | 30~35° / 15~20° | 발이 정강이 축에서 옆으로 30° 넘게 꺾이면 잘못 |
| **팔꿈치** | 경첩 | 굽힘 | 145° (능동), 150° (수동) | 아래팔은 **위팔 앞쪽(손바닥 쪽)으로만** 굽는다. 거꾸로·옆으로 꺾이면 안 된다 |
| | | 폄 | 0° (과신전 5~10°는 유연한 사람) | |
| | 회전 | 회내/회외(pronation/supination) | 75~80° / 80~85° | 손바닥 방향은 아래팔을 제 축으로 비틀어서 만든다 (`palmTo`) |
| **어깨** | 절구+견갑 | 굴곡(앞으로 들기) / 신전(뒤로) | 165~180° / 50~60° | 팔이 등 뒤로 60° 넘게 가면 잘못 |
| | | 벌림(옆으로 들기) / 모음 | 170~180° / 30~45° (몸 앞에서) | |
| | | 안쪽/바깥쪽 회전 | 70~90° / 80~90° (팔꿈치 90° 굽힌 채) | |
| | | 수평 벌림 / 수평 모음 | 30~45° / 130~140° | 어깨 스트레칭(가슴 앞 가로지르기)이 수평 모음의 끝 |
| **손목** | 타원 | 굽힘 / 폄 | 70~80° / 60~75° | 아래팔–손 각이 95° 넘으면 잘못 (바닥을 짚으면 90° 가까이) |
| | | 요측/척측 편위 | 15~20° / 30~35° | |
| **허리(요추)** | | 굽힘 / 폄 | 40~60° / 20~35° | 골반에 대해 척추가 75° 넘게 꺾이면 잘못 (힌지는 골반이 같이 기운다) |
| | | 옆굽힘 / 회전 | 15~20° / 5~15° (흉추 회전 30~35°) | 옆으로 40° 넘으면 잘못 |
| **목(경추)** | | 굽힘 / 폄 | 45~50° / 55~70° | 척추 윗부분과 머리 각이 60° 넘으면 잘못 |
| | | 옆굽힘 / 회전 | 40~45° / 70~90° | 머리가 80° 넘게 돌아가면 잘못 |
| **손가락** | 경첩 | MCP 90°, PIP 100°, DIP 70° | | 주먹은 마디를 손바닥 쪽으로 75°(엄지 40°) 만다 (`GRIP`) |

**경첩 관절(무릎·팔꿈치)이 제일 중요하다.** 방향이 하나뿐이라 조금만 다른 쪽으로 굽어도 바로 이상해 보인다.
- 무릎: 허벅지 뼈를 기준으로 '뒤'가 굽는 쪽. 서 있을 때 발이 뒤로 가는 방향.
- 팔꿈치: 위팔 뼈를 기준으로 '앞(손바닥 쪽)'이 굽는 쪽. T 자세(팔 벌리고 손바닥 아래)에서 손이 앞으로 오는 방향.
- 위팔·허벅지를 제 축으로 돌리면(어깨·고관절 회전) 굽는 방향도 같이 돈다. 그래서 자세를 만들 때 **위팔/허벅지의 비틀림을 굽는 방향에 맞춰야** 팔꿈치·무릎 살이 제대로 접힌다 (move-3d.js 의 경첩 맞추기).

## 2. 운동별로 관절이 어떻게 쓰이나

각 동작에서 움직이는 관절과 범위, 고정하는 관절, 그리고 3D 로 만들 때 자주 나는 이상을 적는다. (L=왼, R=오른)

### 맨몸

- **squat 스쿼트**: 고관절 굽힘 0→90~100°, 무릎 굽힘 0→110~120° (허벅지가 바닥과 평행 이하), 발목 발등 굽힘 25~35°. 상체는 골반과 함께 30~45° 앞으로 기울고 척추는 중립. 무릎은 발끝 방향(둘째 발가락)으로. 이상: 무릎이 안으로 모임(모음), 뒤꿈치가 뜸(발목 과다), 허리 말림.
- **pushup 푸시업**: 팔꿈치 0→90°(가슴이 바닥 5cm 위), 어깨는 굴곡~수평 모음, 팔꿈치는 몸통에서 45° 벌어진다. 고관절·무릎 0° (플랭크), 손목 폄 60~70° (바닥을 짚는다), 발목 발등 굽힘.
- **knee-pushup 무릎 푸시업**: 푸시업과 같되 무릎 90° 굽혀 바닥에 대고 정강이는 **뒤로** 눕는다(발은 들거나 바닥). 이상: 정강이가 앞으로 꺾여 무릎이 거꾸로 됨(TWEAKS 로 정강이를 머리 반대쪽으로 향하게 한 이유).
- **lunge 런지**: 앞다리 고관절 굽힘 ~90°, 무릎 90°(발목 바로 위). 뒷다리는 고관절 폄 0~15° 안에서, 무릎 90°, 발목 발바닥 굽힘(발끝을 세운다). 척추 중립, 골반은 정면. 이상: 뒷다리가 35° 넘게 뒤로 가서 고관절 과신전, 앞무릎이 발끝을 한참 넘음.
- **plank 플랭크**: 어깨 굴곡 90°(팔꿈치는 어깨 바로 아래), 팔꿈치 90°, 고관절 0°(엉덩이가 처지거나 솟지 않음), 무릎 0°, 발목 발등 굽힘(발끝 세움), 목은 척추와 한 줄.
- **crunch 크런치**: 흉추 굽힘 30~40°만(허리는 바닥에), 고관절 45~90°·무릎 90° 세워 고정, 목은 척추와 한 줄(턱 살짝 당김, 목만 꺾지 않음), 팔꿈치 90~120°·손은 귀 옆(머리를 당기지 않는다).
- **bridge 브리지**: 고관절 굽힘 ~45°(무릎 세움)→0°(어깨–엉덩이–무릎 일직선), 절대 폄 쪽으로 넘어가지 않는다. 무릎 90°, 발목 중립, 척추 중립(허리 젖힘 X), 어깨는 바닥, 팔꿈치 0°.
- **burpee 버피**: 스쿼트(고관절·무릎 90°+) → 손 짚고(손목 폄 60~70°) 플랭크(고관절 0°) → 푸시업(팔꿈치 90°) → 점프(고관절·무릎 폄, 발목 발바닥 굽힘, 어깨 굴곡 180°). 각 구간은 위 항목과 같다.
- **one-leg 한 발 서기**: 지지 무릎 5~10°(잠그지 않음), 든 다리 고관절 굽힘 30~45°·무릎 ~90°, 발목 중립, 골반 수평, 척추 중립, 손은 허리.
- **side-plank 사이드 플랭크**: 아래 어깨 벌림 90°(팔꿈치 어깨 바로 아래), 팔꿈치 90°, 척추 옆굽힘 0°(머리–엉덩이–발 일직선), 고관절 0°, 위쪽 어깨 벌림 ~180°(천장), 발은 포갬.
- **dead-bug 데드버그**: 시작 — 고관절 90°·무릎 90°, 어깨 굴곡 90°(팔 천장). 움직임 — 한 어깨 굴곡 90→160°(머리 위로), 반대 고관절 90→20~30°·무릎 90→10~20°(다리를 앞으로), 허리는 바닥에(골반 뒤로 말린 채). 반대 팔다리는 그대로.

### 기구

- **bench-press 벤치프레스**: 어깨 벌림 45~60°(팔꿈치–몸통 각), 팔꿈치 0→90~100°(바가 가슴 아래에 닿을 때), 아래팔은 수직(손목 팔꿈치 위), 손목 중립~살짝 폄, 견갑은 뒤로 모아 고정, 발은 바닥, 허리 자연스러운 아치. 이상: 팔꿈치가 90° 옆으로 벌어짐, 손목이 뒤로 꺾임, 바가 목 위를 지남.
- **deadlift 데드리프트**: 고관절 굽힘 ~90°→0°(힌지가 주된 움직임), 무릎 굽힘 ~40~50°→0°(잠그지 않음), 척추 중립(등이 평평, 골반과 같이 기운다), 팔꿈치 0°(팔은 늘어뜨린 채, 당기지 않음), 어깨는 바 위 살짝 앞, 발목 중립. 잠금에서 고관절을 0° 까지만(허리 젖힘 X).
- **barbell-squat 바벨 스쿼트**: 스쿼트와 같고, 어깨 바깥쪽 회전·팔꿈치 굽힘 ~100°로 바를 등 위(승모근)에 얹는다. 손목 중립~살짝 폄. 바는 발 가운데 위를 수직으로 오르내린다.
- **lat-pulldown 랫풀다운**: 어깨 벌림 ~170°(위)→ 모음·신전으로 팔꿈치가 엉덩이 쪽 ~30°, 팔꿈치 0→~100°, 몸통 10~15° 뒤로만, 견갑 내림. 바는 쇄골~윗가슴까지(목 뒤 X).
- **leg-press 레그프레스**: 고관절 굽힘 ~100°→~20°, 무릎 90°→ 잠금 직전(5~10°), 발목 중립, 등·엉덩이·머리는 패드에(골반 말림 X). 무릎은 발끝 방향.
- **dumbbell-curl 덤벨 컬**: 팔꿈치 0→130~140°, 위팔은 몸 옆에 고정(어깨 굴곡 0~10°), 아래팔 회외(손바닥이 앞→위), 손목 중립, 몸통 반동 X.
- **shoulder-press 숄더프레스**: 시작 어깨 벌림 ~90°·굴곡 30°(팔꿈치는 몸 앞 45° = 스캡션 면)·팔꿈치 90°, 손바닥 앞 또는 마주 → 어깨 180°·팔꿈치 0°(잠금 직전) 머리 위. 손목 중립(덤벨이 팔꿈치 위), 갈비뼈 내림(허리 젖힘 X). 이상: 덤벨이 머리를 지남, 팔꿈치가 뒤로 빠짐.
- **kettlebell-swing 케틀벨 스윙**: 고관절 굽힘 ~70~90°→0°(힌지), 무릎 20~30°만(스쿼트 아님), 어깨 굴곡 0→~90°(가슴 높이, 팔은 느슨한 끈), 팔꿈치 0~10°, 척추·목 중립. 케틀벨은 사타구니 사이를 지나고 무릎 아래로 내려가지 않는다.
- **jump-rope 줄넘기**: 발목 발바닥 굽힘 위주(발끝 착지), 무릎 10~20°, 고관절 거의 0°, 팔꿈치 ~90°로 몸 옆에 고정, 줄은 손목 회전이 돌린다, 어깨 굴곡 0~20°. 줄은 머리 위→앞→발밑→뒤 원을 그리고 몸을 지나지 않는다.
- **cycle 실내 자전거**: 무릎 굽힘 ~30~35°(페달 아래)→~110°(위), 고관절 굽힘 ~40°→~75°, 발목 ±10~15°, 몸통 앞기울기 30~45°, 팔꿈치 20~30°, 손목 중립, 어깨 굴곡 ~60°. 이상: 무릎이 안으로 모임, 발이 페달을 뚫음.
- **rowing 로잉머신**: 캐치 — 무릎 110~120°(정강이 수직), 고관절 굽힘 ~100°(상체 앞으로 1시 방향), 팔꿈치 0°. 드라이브 — 다리→엉덩이→팔 순. 피니시 — 무릎 10°(잠금 X), 몸통 뒤로 ~10~15°(11시 방향), 팔꿈치 ~90~100°, 손잡이는 갈비뼈 아래, 손목 중립, 어깨 신전 ~30°. 리커버리는 반대 순서로 두 배 천천히.
- **treadmill 러닝머신 / run 러닝**: 고관절 굽힘 ~60°/폄 ~15~20°, 무릎 스윙 때 90~120° 접힘·착지 20~30°, 발목 발등/발바닥 ±20~30°, 팔꿈치 ~90° 고정·어깨 앞뒤 ±30°, 몸통 5~10° 앞, 목 중립. 팔은 몸 가운데를 넘지 않는다.
- **walk 걷기**: 고관절 굽힘 30°/폄 10°, 무릎 0→60°(스윙), 발목 발등 10°/발바닥 20°, 팔 어깨 ±15~20°, 팔꿈치 10~20°.
- **stair 계단 오르기**: 고관절 굽힘 60~70°, 무릎 80~90°, 발목 발등 굽힘 20~30°, 상체 살짝 앞, 무릎은 발끝 방향.
- **swim 수영(자유형)**: 어깨 굴곡 180°(리커버리→입수), 팔꿈치 리커버리 90~120°(높게)·당길 때 100~120°(하이 엘보), 몸통 롤 ±40~45°, 발차기는 고관절 ±10~15°·무릎 ~30°, 발목 발바닥 굽힘 최대(발끝 뻗음), 목 중립(숨 쉴 때 머리 회전 ~90°, 몸통 롤과 함께).

### 스트레칭·호흡

- **hamstring-stretch 햄스트링(선 자세)**: 앞다리 고관절 굽힘으로 상체를 60~90° 숙이되 척추 중립(등 평평), 앞 무릎 0°(잠그지는 않음), 앞 발목 발등 굽힘 ~20°(발끝 위), 뒷 무릎은 굽혀 엉덩이를 낮춘다(사람은 20~30°, 우리 캐릭터는 다리가 길어 40°쯤), 손은 허벅지.
- **calf-stretch 종아리(벽)**: 뒷다리 무릎 0°, 발목 발등 굽힘 20~25°(뒤꿈치 바닥), 앞무릎 30~40°, 앞 고관절 굽힘 ~30°, 어깨 굴곡 ~90°(손 벽), 팔꿈치 10~20°. 몸은 머리–엉덩이–뒤꿈치가 한 줄로 기운다.
- **shoulder-stretch 어깨(크로스 바디)**: 스트레칭 팔 어깨 굴곡 90°+수평 모음 110~130°(팔이 가슴 앞을 가로지름), 팔꿈치 0~20°. 반대 손은 팔꿈치 위를 잡고 가볍게 당김(팔꿈치 90~110°). 어깨는 내린 채, 몸통 회전 X. 팔은 가슴 **앞**을 지나지 가슴을 뚫지 않는다.
- **hip-stretch 고관절(반무릎)**: 앞 고관절·무릎 90°, 뒷 무릎 90° 바닥, 뒷 고관절 폄 10~20°(골반을 뒤로 말고 앞으로 2~3cm), 뒷 발목 발바닥 굽힘(발등 바닥), 척추 중립, 손 허리.
- **twist 누워 허리 비틀기**: 한 다리 고관절 굽힘 90°+모음(무릎이 반대편으로 넘어가며 골반 회전 45~60°), 무릎 90°, 척추 회전(흉요추 합 ~45°), 양 어깨 벌림 90°(T 자, 바닥에), 목 회전 반대쪽 60~80°. 반대 손이 넘어간 무릎을 가볍게 누른다.
- **neck-stretch 목(옆)**: 경추 옆굽힘 30~45°(귀를 어깨로), 회전·굽힘 0, 반대 어깨 내림, 같은 쪽 손은 머리 반대편에 얹기(어깨 벌림 ~150°, 팔꿈치 100~120°). 누르지 않는다.
- **deep-breath 복식 호흡**: 관절은 거의 안 움직인다. 팔꿈치 90~110°, 어깨 굴곡 20~40°, 손은 가슴·배 위에 얹는다(뚫지 않는다).

## 3. 3D 에서 이렇게 쓴다

1. **자세는 세상 기준 방향과 손발 목표로 적는다**(PROC). 뼈 기준 각도는 리깅마다 달라서 쓰지 않는다.
2. **경첩 맞추기**: 팔꿈치·무릎을 굽힐 때 아래팔·정강이가 굽는 쪽이 위팔·허벅지의 '앞/뒤'와 맞도록, 위팔·허벅지를 제 축으로 돌린다(어깨·고관절 회전). 손발 목표(IK)의 `bend` 도 이 방향으로 준다.
3. **한계 안에서만**: 위 표의 범위를 넘는 자세는 만들지 않는다. 특히 런지·브리지·데드리프트·힙 스트레칭의 **고관절 폄 ≤ 20°**, 무릎·팔꿈치 **과신전 0°**.
4. **닿는 건 되고 뚫는 건 안 된다**: 손이 허리·머리·허벅지에 얹히고, 기구를 쥐고, 벤치·안장·패드에 앉는 것은 닿음(살이 눌리는 만큼 2~7cm 겹치는 정도까지). 팔이 몸통을 지나거나, 덤벨·바가 머리·몸을 지나거나, 줄이 몸을 지나거나, 살이 바닥 아래로 내려가면 뚫음이다.
   - 리깅 치수를 알아야 바닥에 발이 닿는다: 이 캐릭터는 서면 엉덩이 1.02, 허벅지 0.44, 정강이 0.47, **발목 관절이 바닥에서 0.09**, 평평한 발 뼈는 N(0,-0.53,0.85)(정강이와 60°). 발을 바닥에 둘 땐 발목을 0.09 에, 무릎을 꿇으면 무릎 관절을 0.06 에 둔다.
5. **검사**: `node docs/3d/qa_sample.js <폴더>` 로 관절·기구 자리를 뽑고 `python docs/3d/qa_check.py <폴더> --sheets` 로 검사한다. 규칙과 한계값:
