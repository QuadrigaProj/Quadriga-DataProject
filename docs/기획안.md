# 체력나이 기반 일상 운동 루틴 및 생활활동 처방 서비스

**2026년 국민체육진흥공단 공공데이터 활용 경진대회 · 서비스(웹/앱) 개발 부문**

> 기획안 | 작성 2026.09 | 접수 마감 2026.10.02
> 활용 데이터: 국민체력100 체력인증센터 측정결과 정보 · 국민체력100 동영상 정보
> 팀: 4인 (장예현 · 유민진 · 정다은 · 염윤서)

---

## 한 줄 정의

**측정은 3개월에 한 번, 운동은 매일.**
체력나이로 현재를 알려주고, 매일 같은 시간의 짧은 루틴으로 그 숫자를 움직인다.

---

## 1. 문제 정의

국민체력100은 국가가 운영하는 체력측정·운동처방 체계다.
그러나 측정을 받은 이후가 비어 있다.

### 1-1. 기존 서비스의 한계

| 구분 | 기존 방식 | 한계 |
|---|---|---|
| 국민체력100 | 측정 + 운동처방 제공 | 측정 이후 일상으로 이어지는 경로가 없음 |
| 운동 기록 앱 | 매일 수치를 보여줌 | **매일 보는 숫자는 금방 질린다** |
| 운동 추천 앱 | 사용자가 입력한 목표 기반 | 객관적 체력 데이터와 무관 |
| 홈트레이닝 앱 | 영상 제공 | 무엇을 왜 해야 하는지 근거가 없음 |

### 1-2. 핵심 문제 — 측정의 빈도

운동 앱이 실패하는 지점은 대체로 같다. **매일 숫자를 보여주기 때문이다.**

매일 보는 숫자는 처음엔 자극이지만, 며칠 안에 변하지 않는 숫자가 되고,
변하지 않는 숫자는 곧 무시된다.

반대로 **3개월에 한 번 바뀌는 숫자는 기다림이 된다.**
그 사이 매일의 루틴은 부담 없이 반복되고, 숫자가 움직이는 순간이 다음 3개월의 이유가 된다.

본 서비스는 이 구조를 설계의 중심에 둔다.

---

## 2. 서비스 개요

```
첫 점검     집에서 3항목 자가 측정 → 체력나이 78세 (실제 72세)
                    ↓
목적 선택   6종 중 하나 (다이어트 / 기초체력 / 낙상예방 / 수험생 / 유연성 / 특정운동)
                    ↓
매일        같은 시간, 같은 목소리, 10~15분 루틴
                    ↓
4주마다     강도 자동 상승 (사용자는 인지하지 않음)
                    ↓
3개월       3항목 재점검 → 78세에서 75세로
```

### 설계 원칙

**① 매일은 측정하지 않는다**
매일 하는 것은 루틴뿐이다. 숫자는 3개월에 한 번만 움직인다.

**② 흥미가 앞에서 끌고, 공익이 뒤에 남는다**
사용자를 움직이는 것은 "내 몸이 몇 살인가"라는 호기심이다.
그 결과로 근감소·낙상 예방, 국민체력100 처방의 일상화가 따라온다.
공익을 앞세워 설득하지 않는다.

**③ 화면 하나에 버튼 하나**
전 연령이 쓴다. 홈 화면에서 눌러야 할 것은 하나뿐이다.

## 3. 목적 선택

전 연령을 대상으로 하되, **나이로 나누지 않고 목적으로 나눈다.**
65세에도 본격적으로 운동하는 사람이 있고, 25세에도 가볍게만 하려는 사람이 있다.

첫 점검 직후, 사용자는 **목적 하나만 고른다.**

| 목적 | 설명 | 우선 처방 요인 |
|---|---|---|
| **다이어트** | 체지방 감량과 활동량 증진 | 심폐지구력, 근지구력 |
| **기초 체력 증진** | 특정 목적 없이 전반적 체력 균형 향상 | 6요인 균등 |
| **특정 운동을 위한 체력 증진** | 등산·마라톤·구기 종목 준비 | 종목별 상이 (등산 → 근지구력·평형성) |
| **낙상 예방** | 균형감각·하체 근력 저하로 인한 낙상 위험 감소 | 평형성, 근력 |
| **수험생 체력 증진** | 장시간 앉아 있는 생활에서 오는 체력 저하 관리 | 유연성, 심폐지구력 |
| **유연성 강화** | 관절 가동범위와 스트레칭 능력 개선 | 유연성 |

### 3-1. 목적이 결정하는 것

```
목적  →  ① 매일 루틴의 구성 (어떤 동작을 넣을지)
         ② 약점 지목의 우선순위 (같은 조건이면 목적 요인을 먼저)
         ③ 일상 처방의 종류 (걷기 / 계단 / 스트레칭)
         ④ 추가 측정 여부 (낙상 예방만 +1항목)
```

### 3-2. 목적이 체력나이를 바꾸지는 않는다

목적별로 체력나이 산출 가중치를 다르게 하면,
사용자가 목적을 바꿀 때마다 체력나이가 달라져 지표에 대한 신뢰가 무너진다.

**체력나이는 항상 동일한 기준(3항목 균등)으로 산출한다.**
목적은 **처방 내용과 루틴 구성**에만 반영한다.

### 3-3. 연령대 × 목적 조합

같은 목적이라도 연령대에 따라 기준표와 처방 방향이 달라진다.

| 연령대 | 목적 | 기준표 | 처방 방향 |
|---|---|---|---|
| 20대 | 다이어트 | 20대 기준표 | 유산소 중심, 체지방 관련 보조 지표 안내 |
| 60대 | 낙상 예방 | 60대 기준표 | 평형성 측정 추가, 하체 근력 처방 우선 |
| 10대 | 수험생 체력 증진 | 10대 기준표 | 짧은 스트레칭 + 가벼운 유산소, 학습 컨디션 메시지 |
| 30대 | 특정 운동을 위한 체력 증진 | 30대 기준표 | 선택 종목(등산 등)에 필요한 요인 우선 처방 |

**첫 점검(3항목 → 체력나이)은 목적과 무관하게 공통이다.** 이것이 서비스의 뼈대다.
목적은 나중에 언제든 바꿀 수 있다.

## 4. 체력나이 산출

### 4-1. 왜 직접 만들어야 하는가

국민체력100은 연령대·성별 등급 기준(1~6등급)을 제공하지만
**"체력나이"라는 지표 자체는 제공하지 않는다.**

본 서비스는 공개된 측정결과 데이터의 분포를 분석해 이 지표를 직접 산출한다.
API를 호출해 표시하는 것이 아니라, **공개 데이터를 분석해 새로운 지표를 만드는 작업**이다.

### 4-2. 산출 방식

```
1. 측정결과 데이터에서 성별·연령대별 항목 분포를 구성
2. 사용자의 측정값이 어느 연령대의 중앙값과 일치하는지 역산
   예) 교차윗몸일으키기 32회 → 남성 기준 31세 수준
3. 3항목 환산 나이의 평균 → 체력나이
```

종목군 매핑은 측정결과 데이터의 `pres_note`(실제 운동처방 기록 296만 건)를 집계해 구성한다.
자체 기준을 만들지 않는다. (15-1절)

### 4-3. 필수 측정 3항목

집에서 장비 없이 가능하고, **전 연령 데이터에 존재하는** 항목만 사용한다.

| 체력요인 | 항목 | 필드 | 측정 방법 |
|---|---|---|---|
| 유연성 | 앉아 윗몸 앞으로 굽히기 | `item_f012` | 앉아서 손끝 도달 거리 (cm) |
| 근력·근지구력 | 교차윗몸일으키기 / 의자에 앉았다 일어서기 | `item_f019` / `item_f023` | 앱 타이머 + 횟수 입력 |
| 체성분 | BMI | `item_f018` | 키·몸무게 입력 (계산값) |

**BMI를 축으로 넣은 이유** — 심폐지구력은 집에서 측정할 방법이 없다.
반면 BMI는 계산값이라 측정 오차가 없고, 296만 건 전체에 존재하며, 전 연령 공통이다.
(실측 검증: `item_f018` = 체중 ÷ 신장², 오차 중앙값 0.02)

#### BMI는 원값이 아니라 편차로 환산한다

BMI는 유연성·근력과 성질이 다르다. **높을수록 나쁜 것이 아니라 U자형**이다.
원값을 그대로 역산하면 저체중인 사람이 "젊은 체력"으로 계산되는 오류가 발생한다.

```
✗ BMI 19 → 20대 중앙값과 유사 → 20대 체력으로 환산
✓ |BMI − 22| = 3 → 이 편차가 연령대별 분포에서 어디인지 역산
```

**적정치로부터의 편차 절댓값**으로 변환하면 저체중·과체중이 모두 불리하게 잡히고,
다른 두 축과 동일한 단조 관계가 성립한다.

근육량이 많아 BMI가 높은 경우는 **체지방률(`item_f003`) 선택 측정으로 보정**한다.
체지방률을 입력하면 BMI 축을 체지방률 축으로 대체한다.

### 4-4. 선택 측정 — 심폐지구력·평형성

필수 3항목만으로도 체력나이는 산출된다.
아래는 **밖에서 잴 수 있는 사용자**를 위한 선택 항목이다.

| 체력요인 | 항목 | 필드 | 장소 |
|---|---|---|---|
| 심폐지구력 | 6분 걷기 (거리 m) | `item_f024` | **산책로·운동장** |
| 심폐지구력 | 2분 제자리 걷기 (회) | `item_f025` | 집 |
| 심폐지구력 | 왕복오래달리기 (회) | `item_f021` | 운동장·체육관 (20m 구간) |
| 평형성 | 8자 보행 (초) | `item_f027` | 집·복도 |
| 민첩성 | 3m 표적 돌아오기 (초) | `item_f026` | 집·복도 |

**선택 측정은 체력나이를 바꾸지 않는다.**
체력나이는 항상 필수 3항목으로 산출한다(3-2절 원칙).
선택 항목은 **스포츠 프로필의 축을 늘리고, 약점 지목의 정확도를 높이는 데 사용**한다.

```
필수 3항목만  →  체력나이 + 프로필 별점 3축
선택 측정 추가 →  체력나이 동일 + 프로필 별점 5축 + 더 정확한 처방
```

측정할수록 결과가 정밀해지되, **안 재도 서비스가 성립한다.**
이것이 온보딩 이탈을 막는 핵심 장치다.

> 자유 러닝(산책로를 임의 거리로 달리기)은 국민체력100 측정 항목이 아니어서
> 등급 기준표와 대조할 수 없다. **6분 걷기처럼 공식 항목의 규격을 그대로 따라야**
> 체력나이 환산이 가능하다.

### 4-5. 연령군별 항목 코드는 실제로 다르다

측정결과 데이터(5,000건 표본) 확인 결과, 연령군마다 채워지는 필드가 다르다.

| 연령군 | 고유 항목 코드 |
|---|---|
| 성인 | `f019` `f020` `f021` `f022` |
| 어르신 | `f023` `f024` `f025` `f026` `f027` |
| 청소년 | `f010` `f013`~`f017` `f030` |
| 유소년 | `f009` `f042`~`f044` |

**전 연령 공통 필드**: `f001`(신장) `f002`(체중) `f003`(체지방률)
`f007`·`f008`(악력) `f012`(유연성) `f018`(BMI) `f028`(상대악력)

연령군별로 환산표를 따로 두되, **역산 로직은 하나로 유지**한다.

### 4-6. 항목 코드 판독 결과

API 명세에는 `item_f001`~`item_f052`의 필드명만 있고 설명이 없다.
5,000건 표본의 값 범위와 계산식 검증으로 다음을 확정했다.

| 필드 | 범위 (중앙값) | 항목 | 확정 근거 |
|---|---|---|---|
| `f001` | 142~191 (162) | 신장 | 범위 |
| `f002` | 35.8~121 (60.6) | 체중 | 범위 |
| `f003` | (24.7) | 체지방률 | 범위 |
| `f007`/`f008` | (29.4/28) | 악력 좌·우 | 범위 |
| `f012` | **-15**~143 (16) | 앉아윗몸앞으로굽히기 | **음수 존재 — 유연성 항목만 가능** |
| `f018` | (23.1) | BMI | **체중÷신장² 일치 (오차 0.02)** |
| `f019` | 0~71 (30) | 교차윗몸일으키기 | 범위 |

**이 판독 작업 자체가 공공데이터 활용 실적이다.**
명세에 없는 필드를 데이터 분석으로 복원한 과정을 사례보고서에 기술한다.

### 4-7. 측정 오차 보정

자가 측정은 자세와 방식에 따라 오차가 발생한다.
**2cm를 잘못 재서 체력나이가 3살 뛰면 사용자는 지표를 신뢰하지 않는다.**
자가 측정 모드에서는 다음 보정을 적용한다.

| 보정 | 방식 | 목적 |
|---|---|---|
| **윈저화(Winsorizing)** | 연령·성별 상·하위 5% 값으로 캡핑 | 극단값이 결과를 지배하지 않게 |
| **변화폭 제한** | 점검 1회당 체력나이 변동 ±5세로 제한 | 오입력으로 인한 급변 방지 |
| **3회 중 중앙값** | 측정 3회 권장, 중앙값 채택 (선택) | 단발 오차 제거 |
| **신뢰구간 표기** | "체력나이 27세 (±2세)" | 정밀도를 과장하지 않음 |

신뢰구간을 함께 표시하는 것이 중요하다.
**단일 숫자로 단정하면 오차가 드러날 때 신뢰가 무너지지만,
범위로 제시하면 오차가 설계에 포함된 것이 된다.**

체력인증센터 측정값을 입력하면 보정 없이 원값을 사용하고, 신뢰구간 표기를 제거한다.

### 4-8. 정확도와 국민체력100 연결

**"참고용 추정치"임을 화면에 명시**하고, 정확한 값을 원하는 사용자에게는
가까운 체력인증센터의 무료 측정을 안내한다.

이는 서비스의 한계가 아니라 **국민체력100 이용을 유도하는 접점**이다.
센터에서 측정한 값을 입력하면 그 값으로 갱신된다.

## 5. 스포츠 프로필과 약점 우선순위

### 5-1. 스포츠 프로필 — 어디가 약한가

체력나이가 **"얼마나"**라면, 스포츠 프로필은 **"어디가"**다.
같은 3항목 측정값에서 둘 다 산출되므로 추가 측정이 필요 없다.

```
체력나이 78세
──────────────
근력      ★★☆☆☆
유연성    ★★★★★
심폐지구력 ★★★★☆
```

3개월 재점검 시 **별의 개수가 움직인다.**
체력나이라는 한 줄 요약이 바뀌는 이유를 시각적으로 설명해준다.

사용자는 자신을 "운동을 안 하는 사람"이 아니라
**"유연성은 좋은데 근력이 약한 사람"**으로 이해하게 된다.

### 5-2. 약점 하나만 지목한다

전체를 골고루 올리라는 조언은 실행되지 않는다.
**어디부터 손대야 가장 효율적인지**를 하나만 찍어준다.

> **지금 당신의 체력나이를 가장 많이 낮추는 것은 근력입니다.**
> 근력만 또래 평균 수준으로 올리면 → **78세 → 74세**

#### 계산 방식

체력나이는 3항목 환산 나이의 평균이므로,
**각 항목을 또래 평균까지 올렸을 때의 체력나이를 전부 계산해보고
가장 크게 떨어지는 항목을 선택**하면 된다.

```
현재         근력 84세 · 유연성 68세 · 심폐 72세  → 체력나이 78세

근력만 개선  근력 72세 · 유연성 68세 · 심폐 72세  → 74세  (-4)  ← 선택
유연성만     근력 84세 · 유연성 65세 · 심폐 72세  → 77세  (-1)
심폐만       근력 84세 · 유연성 68세 · 심폐 70세  → 77.3세 (-0.7)
```

별도의 근거 데이터가 필요 없다. **우리가 만든 지표 위에서의 산술 계산**이다.
심사에서 근거를 질문받으면 계산식을 그대로 보여주면 된다.

#### 예측이 아니라 도달값이다

**"4주 뒤 74세가 됩니다"라고 말하지 않는다.**
운동량과 체력 향상의 관계를 뒷받침할 데이터가 공공데이터에 없기 때문이다.

**"근력이 또래 평균이 되면 74세로 계산된다"**까지만 제시한다.
기한을 약속하지 않고, 도달 조건만 제시한다.

#### 루틴과의 연결

지목된 약점이 그대로 **매일 루틴의 구성 기준**이 된다.

```
약점 지목 (근력)
      ↓
매일 루틴이 근력 중심으로 구성됨
      ↓
3개월 재점검 → 근력 ★★☆☆☆ → ★★★☆☆
      ↓
체력나이 78 → 75  ·  근력 루틴 4개 해금
```

**프로필 → 약점 지목 → 루틴 → 재점검 → 해금**이 하나의 고리로 이어진다.

## 6. 루틴 설계

### 6-1. 매일 — 같은 시간, 같은 형식

| 요소 | 설계 | 이유 |
|---|---|---|
| 시간 | 사용자가 정한 고정 시각 | 예측 가능성이 습관을 만든다 |
| 길이 | 10~15분 (목적에 따라 5~15분) | 부담 없이 매일 가능한 길이 |
| 형식 | 같은 목소리·같은 순서 | 매번 다르면 판단이 필요해진다 |
| 화면 | 버튼 하나 | 고민할 여지를 만들지 않는다 |

### 6-2. 몸 무거운 날 버튼

컨디션이 나쁜 날을 위한 버튼을 홈에 둔다. 누르면 그날의 루틴이 절반 길이·저강도로 바뀐다.
**"오늘은 건너뛴다"를 "오늘은 가볍게 한다"로 바꾸는 장치**다.

### 6-3. 부위 필터

무릎·허리·어깨 중 불편한 부위를 선택하면 해당 부위에 부담이 가는 동작을 제외한다.
(`trng_part_nm` 필드로 필터링)

### 6-4. 4주마다 강도 상승

**동영상 데이터에 주차·단계 값이 없음을 확인했다(15절).**
세트·반복 횟수를 자체 규칙으로 점증한다. 영상은 동일하게 유지한다.

```
1~4주   10회 × 2세트
5~8주   12회 × 3세트
9~12주  15회 × 3세트
```

**사용자에게 알리지 않는다.** 매일 같은 루틴을 하고 있다고 느끼는 것이 중요하다.

## 7. 미래 보기 — 목표 설정

5-2가 **"어디를 고칠지"**를 정해준다면, 7절은 사용자가 **"어디까지 갈지"**를 정한다.

```
현재: 체력나이 78세 (근력 ★★, 유연성 ★★★★★, 심폐 ★★★★)
목표: 75세
→ 근력을 또래 평균 수준까지 올리면 체력나이 75세로 산출됨
→ 근력 중심 루틴으로 자동 전환
```

### 예측이 아니라 계산이다

**"이 운동을 하면 3개월 뒤 젊어집니다"라고 예측하지 않는다.**
그런 예측을 뒷받침할 데이터가 공공데이터에 없기 때문이다.

**"이 수치가 이만큼 되면 체력나이가 이렇게 계산된다"**까지만 제시한다.
실제 변화는 3개월 재점검으로 확인한다.

이 구분은 심사에서 근거를 질문받았을 때 방어 가능한 유일한 선이다.

---

## 8. 루틴 해금

3개월 점검에서 특정 체력요인이 향상되면 새로운 루틴이 열린다.

```
유연성 ★★★☆☆ → ★★★★☆
→ 새로 열린 루틴 4개
```

"테니스가 해금되었습니다" 같은 방식은 쓰지 않는다.
종목별 요구 체력 기준이 공공데이터에 없어 우리가 지어내야 하기 때문이다.

대신 **동영상 데이터의 난이도 값을 기준으로 해금**한다. 데이터에 존재하는 값이라 근거가 명확하다.
해금은 3개월 점검의 보상이다. **기다림에 대한 답이 숫자 하나가 아니라 둘이 된다.**

## 9. 일상 처방

측정 결과에 따라 일상 활동 제안이 달라진다.

| 하지근력 등급 | 계단 제안 |
|---|---|
| 상위 | 3층 이내는 계단으로 올라가기 |
| 중간 | 올라갈 때만 계단, 내려올 땐 엘리베이터 |
| 하위 | 계단 대신 한 정거장 먼저 내려 걷기 |

일반 건강앱은 누구에게나 "계단을 이용하세요"라고 말한다.
본 서비스는 **측정 결과에 따라 다르게 말한다.**
무릎 관절 부담과 낙상 위험이 있는 사용자에게 무조건 계단을 권하지 않는다.

### 거리 기반 제안

교통 데이터 없이 좌표 두 개의 거리 계산만으로 구현한다.

- 도보 20분 이내 → 걸어가기 제안
- 그 이상 → 제안하지 않음 (무리한 제안은 신뢰를 떨어뜨린다)

자전거 대여는 **제출 범위에서 제외한다.** 대여소 위치 데이터가 없으면 공허한 문구가 되고,
균형 능력이 낮은 사용자에게는 위험하다.

## 10. 짬 보너스

메인 루틴을 **대체하지 않고 추가**한다.

```
메인 루틴   하루 1회 · 같은 시간 · 10~15분 · 고정   ← 습관 축
짬 보너스   등록한 빈 시간 · 3~5분 · 선택          ← 추가분
```

"매일 같은 시간"이 핵심인데 불규칙한 알림이 뜨면 안정감이 깨진다.
따라서 메인을 하지 않고 짬만 채운 날은 **완료로 처리하지 않는다.**

빈 시간은 시간표를 자동 인식하지 않고 **자주 비는 시간 2~3개를 직접 등록**받는다.
이미지 인식은 정확도 편차가 크고 개발 리스크가 높다.

## 11. 가족 공유 — 안심 릴레이

주 1회, 지정한 가족에게 한 줄 요약을 보낸다.

### 11-1. 감시가 아니라 안부여야 한다

```
✗ "이번 주 루틴 2/7회 완료"          → 성적표. 미달성이 드러남
✓ "이번 주 어머니가 3번 운동하셨어요"  → 안부. 한 일만 전달
```

**미달성은 전송하지 않는다.** 한 번도 못 한 주에는 메시지가 나가지 않는다.
자녀에게 불필요한 불안을 주지 않고, 어르신에게 "안 하면 들킨다"는 압박을 주지 않는다.

### 11-2. 응원하기 — 알림을 접점으로 바꾼다

자녀 화면에는 경고 대신 **응원하기 버튼**만 둔다.
보낸 응원은 어르신 앱의 루틴 시작 화면에 표시된다.
**리포트가 감시 도구가 아니라 대화의 계기가 된다.**

### 11-3. 통제권은 어르신에게 둔다

- 수신자 지정·해제는 **어르신 본인만** 가능
- 상세 수치(체력나이, 측정값)는 전송하지 않는다. 횟수만 보낸다
- 언제든 공유를 끌 수 있고, 껐다는 사실도 자녀에게 알리지 않는다

젊은 사용자에게는 기본 꺼짐이다. **하나의 기능으로 두 사용자층을 커버한다.**

## 15. 데이터 사전 검증 결과

| 확인 항목 | 결과 |
|---|---|
| 레코드 수가 충분한가 | ✅ **2,957,287건** |
| 성별 필드가 있는가 | ✅ `test_sex` (F/M) |
| 연령 정보가 있는가 | ✅ `age_class` `age_degree` `age_gbn` |

### 15-1. 예상 밖의 수확 — 운동처방이 데이터에 있다

측정결과 데이터에 **`pres_note`** 필드가 있고, 실제 처방 내용이 텍스트로 들어 있다.

```
"본운동:배스트레칭,상지 루틴 스트레칭,옆구리 스트레칭,엉덩이 스트레칭,목 스트레칭"
"본운동:전신 루틴 스트레칭,달리기,엎드려 버티기,소파를 이용한 윗몸올리기,뒤꿈치 들기"
```

**체력요인 → 종목 매핑을 자체적으로 만들 필요가 없다.**
296만 건의 실제 처방 기록을 집계해, 유사한 측정 프로필을 가진 이용자에게
국민체력100이 실제로 무엇을 처방했는지를 근거로 삼는다.

심사에서 처방 근거를 질문받을 경우, 공단이 실제로 내린 처방이라고 답할 수 있다.

### 15-2. 대응이 필요한 항목 — 강도 자동 상승

**"국민체력100 커리큘럼 기반 4주 강도 상승"이라는 표현은 사용할 수 없다.**
세트·반복 횟수를 자체 규칙으로 점증하고, 사례보고서에
**"운동 강도 점증 원칙에 따른 자체 설계"**로 명시한다.

## 부록 D. 심사 예상 질문과 답변

### Q1. BMI가 체력 지표인가?

맞는 지적이다. 다만 세 가지 이유로 축에 포함했다.

1. **현실적 제약** — 심폐지구력은 집에서 장비 없이 측정할 방법이 없다
2. **데이터 완전성** — 296만 건 전체에 존재하는 유일한 전 연령 공통 축이며, 측정 오차가 없는 계산값이다
3. **연령별 임상적 의미** — 60대 이상에서 저체중·과체중은 근감소증·낙상 위험과 직접 연계된다

방법론적으로도 원값을 쓰지 않는다. U자형이므로 적정치(22)로부터의 편차 절댓값으로 변환해
단조 관계를 확보했다(4-3절). 근육형 과체중은 체지방률 선택 측정으로 보정한다.

### Q2. 집에서 잰 값을 믿을 수 있나?

믿을 수 없다는 전제로 설계했다.

- **"27세 (±2세)"**처럼 신뢰구간과 함께 표시
- 연령·성별 상하위 5% 캡핑
- 점검 1회당 변동 ±5세 제한
- 센터 측정값 입력 시 보정 없이 원값 사용

**정밀도를 과장하지 않는 것이 신뢰를 얻는 방법**이며, 동시에 센터 방문을 유도하는 장치다.

### Q3. 체력나이는 공식 지표가 아니지 않나?

맞다. 국민체력100은 등급(1~6)은 제공하지만 체력나이는 제공하지 않는다.
**공개 데이터 296만 건의 성별·연령대별 분포를 분석해 자체 산출**했으며, 산출식을 화면에 명시한다.

명세에 설명이 없는 필드도 값 범위와 계산식으로 복원했다(4-6절).
BMI(오차 0.02)와 상대악력(오차 0.09)이 정확히 일치해 판독 방법의 타당성이 확인됐다.

### Q4. 운동처방의 근거는 무엇인가?

자체 기준을 만들지 않았다. `pres_note` 필드에 **공단이 실제로 내린 처방 296만 건**이 들어 있다.
유사한 측정 프로필의 이용자에게 무엇을 처방했는지를 집계해 사용한다(15-1절).

### Q5. 이미 있는 운동 앱과 무엇이 다른가?

1. **측정 빈도** — 매일 숫자를 보여주지 않는다. 3개월에 한 번만 움직인다
2. **객관적 데이터 기반** — 사용자 입력 목표가 아니라 국가 체력측정 체계의 기준을 쓴다
3. **끊긴 고리를 잇는다** — 국민체력100의 처방을 일상에서 실행할 경로를 만든다

### Q6. 가족 공유가 감시로 느껴지지 않겠나?

그래서 **미달성은 전송하지 않는다.** 한 일만 전달한다.
자녀 화면에는 경고 대신 응원 버튼만 두고, 수신자 지정·해제 권한은 어르신 본인에게 있다(11절).

### Q7. 3개월 효과를 어떻게 검증했나?

검증하지 못했다. 개발 기간이 3개월보다 짧다. 시연은 준비된 데이터로 하며 그 사실을 명시한다.

다만 서비스는 효과를 **예측하지 않는다.** "이 운동을 하면 몇 살 젊어진다"가 아니라
"이 수치가 이만큼 되면 이렇게 계산된다"까지만 제시하므로, 검증되지 않은 주장을 하지 않는다(7절).
